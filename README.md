# PULSE Training Club Website
Responsive fitness-club concept website using HTML, CSS, and vanilla JavaScript.

## Pages
- `index.html` — Landing page
- `programs.html` — Training programs
- `coaches.html` — Coach profiles
- `about.html` — Club philosophy
- `contact.html` — Membership/consultation enquiry

## Features
- Responsive CSS Grid and Flexbox
- Mobile navigation menu
- Enquiry form validation + demo confirmation
- External CSS and JavaScript
- Unsplash photography and Google Fonts

## Run
Open `index.html` in a browser. No build tools required.

## Production notes
Replace fictional coach profiles, sample copy, and contact details with approved client content. The form only displays a demo message; connect a backend or form service to collect real enquiries. This is a front-end template, not a live membership/payment system.
